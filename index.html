Project7

A simple Windows optimization utility focused on practical maintenance and better performance for low-to-mid end PCs.

Download Project7

What it does

Useful tools without unnecessary system tweaks.

Temporary file cleanup

Removes common temporary files and the Windows thumbnail cache.

Drive optimization

Uses Windows' built-in drive optimization process.

System repair

Runs Microsoft's built-in DISM and SFC repair tools.

Network refresh

Flushes DNS and refreshes common Windows networking components.

Power plans

Provides High Performance and Balanced power-plan switching.

Activity log

Keeps a simple Project7 log of completed maintenance actions.

Project7 does not edit the Windows registry and does not require third-party software.

Download Project7

Download the Windows batch file and run it as Administrator for access to all available maintenance functions.
